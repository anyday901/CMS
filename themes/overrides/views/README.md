# Template overrides

Copy a view from `resources/views` here, at the same path, to change it for this site only. For example, `resources/views/portal/dashboard.blade.php` becomes `themes/overrides/views/portal/dashboard.blade.php`.

Overrides apply on top of whichever theme is active, and the updater never touches this folder. Admin pages can't be overridden. After an update, compare your copies with the new originals in case they changed.
